# Strole Consulting Website

Official website for **Strole Consulting**, an independent IT consulting and technology services business providing reliable technical solutions since 2000.

The website presents services including IT consulting, computer repair, hardware and software support, cybersecurity, networking, smart home setup, equipment sourcing, and custom software solutions.

## Live Website

https://stroleconsulting.com

## Features:

* Responsive single-page design
* Modern dark technology-themed interface
* Custom animations and interactive effects
* Services and capabilities sections
* Professional background and experience timeline
* Contact form powered by Web3Forms
* Custom domain hosted through GitHub Pages
* Search engine and social media metadata
* Custom favicon and branding

## Local Development

No build tools or dependencies are required.

Clone the repository:

```bash
git clone https://github.com/deividas-strole/strole-consulting.git
```

Open the project folder:

```bash
cd stroleconsulting
```

Then open `index.html` directly in a browser.

You can also run a simple local server:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Contact Form

The website contact form uses Web3Forms to process inquiries without requiring a custom backend.

The form submits requests to:

```text
https://api.web3forms.com/submit
```

A valid Web3Forms access key must be included in the form configuration.

## Deployment

The website is deployed through GitHub Pages.

The custom domain is configured with:

```text
stroleconsulting.com
```

The repository includes a `CNAME` file containing the custom domain.
